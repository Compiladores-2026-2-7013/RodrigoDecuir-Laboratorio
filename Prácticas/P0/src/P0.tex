\textbf{Preguntas} \\

\textbf{Use el siguiente comando: \texttt{cpp programa.c programa.i} \\
Revise el contenido de \textit{programa.i} y conteste lo siguiente:}

\begin{enumerate}[label=\alph*.]
  \item \textbf{¿Qué ocurre cuando se invoca el comando \textit{cpp} con esos argumentos?}
    \textcolor{red}{cpp es el preprocesador de c, por lo que al ejecutar el comando con
    esos argumentos se lee programa.c, se preprocesa y se escribe el programa fuente modificado
    en el archivo \textit{programa.i} \\ La extensión \textit{.i} se usa para código que no debe
    de ser preprocesado (en este caso \textit{programa.i} ya no debe de ser preprocesado porque
    básicamente es el contenido preprocesado de \textit{programa.c})}
  \item \textbf{¿Qué similitudes encuentra entre los archivos \textit{programa.c} y \textit{programa.i}?}
    \textcolor{red}{programa.i cuenta con todo lo que existía en programa.c y más, pues en el archivo
    preprocesado (programa.i) ya se cuenta con las macros expandidas, el reemplazo de los comentarios
    por espacios en blanco, entre otras fases que forman parte de la traducción del preprocesador.}
  \item \textbf{¿Qué pasa con las macros y los comentarios del código fuente original en \textit{programa.i}?}
    \textcolor{red}{Los comentarios se reemplazan por espacios en blanco y las macros se expanden, es decir,
    se reemplaza su llamada por la definición completa correspondiente.}
  \item \textbf{Compare el contenido de \textit{programa.i} con el de \textit{stdio.h} e indique de forma
    general las similitudes entre ambos archivos.}
    \textcolor{red}{Como \textit{stdio.h} es un header que se incluyó en programa.c vamos a tener que todo
    su contenido prácticamente se copia y pega a \textit{programa.i}, de este modo, como similitud podríamos
    decir que uno contiene al otro.}
  \item \textbf{¿A qué etapa corresponde este proceso?}
    \textcolor{red}{Al programa fuente modificado. Justo después de pasar por el preprocesador.}
\end{enumerate}

\textbf{Ejecute la siguiente instrucción: \texttt{gcc -Wall -S programa.i}}

\begin{enumerate}[label=\alph*.]
  \item ¿Para qué sirve la opción \textit{-Wall}? \textcolor{red}{Para habilitar todas las
    advertencias que vienen dadas por escribir código de forma cuestionable y que usualmente
    son fáciles de modificar para prevenir que se lance una advertencia. Asimismo, se revisan
    las macros y se lanza una advertencia en caso de que alguna se encuentre escrita de forma
    cuestionable.}
  \item ¿Qué le indica a gcc la opción \textit{-S}? \textcolor{red}{Que gcc se detenga antes
    de ensamblar. Asimismo existen las opciones -c y -E para detener la compilación en otras
    etapas.}
  \item ¿Qué contiene el archivo de salida y cuál es su extensión? \textcolor{red}{El código
    traducido a lenguaje ensamblador. Su extensión es .s}
  \item ¿A qué etapa corresponde este comando? \textcolor{red}{Al momento en que se obtiene
    el programa objeto en lenguaje ensamblador (justo antes de ensamblar).}
\end{enumerate}

\textbf{Escribe un segundo programa en lenguaje \texttt{C} en el que agregue 4 directivas del preprocesador
de \texttt{C} (\textit{cpp}). Las directivas elegidas deben jugar algún papel en el significado del programa,
ser distintas entre sí y diferentes de las utilizadas en el primer programa (aunque no están prohibidas si las requieren).}

\begin{verbatim}
#include <stdio.h>
#include <stdlib.h>

#define ll long long
#define max(a,b) (a<b?b:a)
#define abs(x) (x<0?(-x):x)
#define FOR(i,a,b) for (int i = (a); i < (b); ++i)

/**
  * Compiladores 2026-2
  */
int main(void) {
  FOR(i,1,10) printf("-");
  printf("\nNúmero más grande entre abs(-1000000000000000000) y 3000000000000000000\n");
  FOR(i,1,10) printf("-");
  printf("\n");

  ll numero_negativo = -1000000000000000000LL;
  ll numero_positivo = 3000000000000000000LL;

  ll resultado = max(abs(numero_negativo), numero_positivo);
  printf("Resultado : %lld\n", resultado);
  return 0;
}
\end{verbatim}

  \item Explique su utilidad general y su función en particular para su programa.
\begin{verbatim}
ll long long
utilidad general: alias para acortar un tipo muy largo
función en particular: precisamente acortar el tipo que es bastante largo

max(a,b) (a<b?b:a)
utilidad general: obtener el máximo entre dos números
función en particular: precisamente obtener el máximo entre dos números

abs(x) (x<0?(-x):x)
utilidad general: convierte un número negativo en positivo
función en particular: precisamente tomar el valor absoluto de un número negativo

función en particular: justo para acortar el for

\end{enumerate}
